# 📊 HR Analytics Dashboard

## 📌 Project Overview
This project is a professional **HR Analytics Dashboard** developed using **Power BI** to analyze employee data and uncover insights related to workforce management, employee attrition, demographics, salary distribution, and departmental performance.

The dashboard helps organizations make data-driven HR decisions by visualizing key metrics and trends in an interactive format.

## 📈 Key Insights

- Total Employees: **1,417**
- Active Employees: **1,186**
- Attrition Count: **231**
- Attrition Rate: **16.3%**
- Highest attrition observed in:
  - Administration
  - Sales
  - Operations
- Majority employees belong to the **26–35 age group**

## 📌 Final Conclusion

The HR Analytics Dashboard successfully provides meaningful insights into employee demographics, workforce distribution, and attrition patterns within the organization. By leveraging Power BI visualizations and data analysis techniques, the dashboard helps identify key areas affecting employee retention and overall HR performance.

The analysis revealed that attrition is higher in specific departments such as Administration, Sales, and Operations, while the majority of employees belong to the 26–35 age group. Salary distribution, experience trends, and gender-based analysis further contribute to understanding workforce behavior and organizational dynamics.

This project demonstrates the effective use of Business Intelligence tools for transforming raw HR data into actionable insights that support strategic decision-making. The dashboard can assist HR teams in improving employee satisfaction, reducing attrition, and optimizing workforce management.

Overall, this project highlights the importance of data-driven HR analytics in modern organizations and showcases practical skills in Power BI, data visualization, and analytical thinking.
